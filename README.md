## Projects and Technical Work

**Message Bus**

Development and testing of Message Bus and Subscription Bus Module. Working with interprocess communication, message exchange and subscription mechanisms using C++ and POSIX Shared Memory.

**O-RAN M-Plane**

Working with the O-RAN Management Plane (M-Plane) specification for O-RU devices. Studying and testing management procedures, notifications and configuration management using NETCONF and YANG.

**O-RU / O-DU**

Exploring management-plane interaction between O-RAN Radio Unit (O-RU) and O-DU. Working with software management procedures, event notifications, alarms and configuration data.

**IoT and Embedded Systems**

Development of multiple hardware and software projects using Arduino, ESP8266 and ESP32 microcontrollers. Working with microcontroller programming and embedded applications.

**Web and Mobile Development**

Developing web applications using React and TypeScript, as well as Android applications using Kotlin and Jetpack Compose.
